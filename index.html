How it works FAQ

Proof of existence

Prove it existed.

Drop a file or paste a link. Stamp seals its fingerprint with a trusted time, so you can show that it existed and has not changed since. Your file never leaves your device.

We fetch the page once and seal the exact bytes we received. You get a copy of that snapshot to keep.

Three quiet steps

  1. Fingerprint. Your browser turns the file into a short unique code. Change one pixel and the code changes completely.
  2. Seal. We ask an independent time authority to sign that code, and anchor it to the Bitcoin blockchain for permanence.
  3. Prove. Share the certificate link. Anyone can drop the file on it and see if it matches.

Good to know

Do you store my files?

No. Only the fingerprint, the time and the optional file name are saved. Files are never uploaded. For websites we fetch the page once, show you the snapshot and do not keep it.

What does a stamp prove?

That a file with exactly this fingerprint existed no later than the time shown. It does not prove who made it, and it is not legal advice. Rules about legal weight differ by country.

Can I check a stamp without trusting you?

Yes. Download the proof files from any certificate. The .tsr file can be checked with OpenSSL, and the .ots file with the free OpenTimestamps tools.

Why a website snapshot?

Web pages change. We stamp the exact page we received at that moment, and you keep the file. Dynamic pages may look different later, which is why the snapshot matters.
